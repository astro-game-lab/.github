# Support

Thanks for playing with astro-game-lab! This document explains where to go for help.

## Before asking for help

1. **Check the repository's README and documentation.** Most common questions are answered there.
2. **Search existing issues and discussions.** Someone may have already asked the same question.
3. **Check the repository's `CONTRIBUTING.md`** for project-specific guidance.

## Where to ask

### Questions and usage help

- **[GitHub Discussions](https://github.com/orgs/astro-game-lab/discussions)** is the best place for questions, ideas, game concepts, and general conversation.
- For project-specific questions, use the Discussions tab of the relevant repository if it has one enabled.

### Bug reports

- Open an issue on the affected repository using the **bug report** template.
- Include steps to reproduce, the version you are playing, and your platform. For a browser game, include the browser and version.
- If the game has one, attach the **seed and scenario** — without them, a simulation bug is often impossible to reproduce.

### "The physics looks wrong"

- Use the **physics discrepancy** template rather than the general bug report.
- Tell us what you expected and where that expectation comes from — a textbook value, GMAT, JPL Horizons, or a hand calculation. That reference is the most useful part of the report.

### Feature requests and game ideas

- Open an issue on the affected repository using the **feature request** template.
- Describe the experience you want, not just the mechanic. What should it feel like to play?

### Playtest feedback

- Open a Discussion. Tell us where you got stuck, bored, or confused, and what you were trying to do at the time. Negative feedback is welcome and useful — we would rather hear it than not.

### Security issues

- **Do not file security issues publicly.** See [SECURITY.md](SECURITY.md) for our private reporting process.

## What is not supported here

- One-on-one technical support or consulting.
- Homework or coursework help — we welcome conceptual questions about orbital mechanics but will not complete assignments.
- Help with third-party tools we don't maintain (game engines, GMAT, SPICE, external libraries). For those, please contact the respective projects.

## Response expectations

astro-game-lab is a volunteer-driven community. Please be patient — maintainers answer questions as time allows. You are welcome and encouraged to help answer others' questions as well.
