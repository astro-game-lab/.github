# .github

Organization-level configuration for [astro-game-lab](https://github.com/astro-game-lab).

## What lives here

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The organization profile, rendered at [github.com/astro-game-lab](https://github.com/astro-game-lab). |
| `CODE_OF_CONDUCT.md` | Org-wide code of conduct. |
| `CONTRIBUTING.md` | Org-wide contributing guide. |
| `GOVERNANCE.md` | How the organization is run and how decisions are made. |
| `SECURITY.md` | Vulnerability reporting policy. |
| `SUPPORT.md` | Where to get help. |
| `ISSUE_TEMPLATE/` | Default issue forms, including the physics discrepancy report. |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template. |
| `LICENSE` | Licence for the contents of *this* repository. |

## How the defaults work

GitHub uses the community health files here as **defaults for every public repository in the organization that does not define its own**. A repo that adds its own `CONTRIBUTING.md` overrides the one here; a repo that adds nothing inherits all of it.

Two things this does **not** cover:

- **`LICENSE` is never inherited.** Every repository needs its own licence file. Org convention is MIT for code and CC BY 4.0 for game assets — see [CONTRIBUTING.md](CONTRIBUTING.md#assets-and-licensing).
- **`README.md` is never inherited.** Every repository needs its own.

Changes here take effect across the organization immediately, so review them the way you would review shared code.

## Contributing

Improvements to these documents are welcome — open a pull request. Material changes to `GOVERNANCE.md` should be discussed first in [Discussions](https://github.com/orgs/astro-game-lab/discussions).
